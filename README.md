Next.js Motion Starter

A production-ready starter for building fast, premium-quality websites with modern technologies.

Features

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- GSAP animations
- Lenis smooth scrolling
- Motion animations
- Drizzle ORM
- PostgreSQL
- Zod validation
- React Hook Form
- Modular design system
- SEO-ready architecture
- API routes
- Production-oriented project structure

Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

Build for production:

npm run build

Run the production server:

npm start
